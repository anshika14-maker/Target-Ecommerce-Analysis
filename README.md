# Target E-commerce Sales & Operations Analysis

## 📌 Project Overview

This project analyzes e-commerce sales and operations data to understand customer behavior, order trends, sales performance, freight costs, and delivery performance.

The analysis was performed using SQL to generate business insights and recommendations.

## 🛠️ Tools & Technologies

- SQL
- Google BigQuery
- CTEs
- Window Functions
- Aggregate Functions
- Date Functions

## 🎯 Business Objectives

- Analyze month-on-month order trends across states
- Understand customer distribution across states
- Analyze order value and sales performance
- Compare freight costs across states
- Analyze delivery time and delivery delays
- Identify patterns that can support business decisions

## 💡 Business Recommendations

- Focus promotions on states with high customer and order volumes.
- Use targeted offers to improve customer acquisition in states with lower customer counts.
- Investigate regions with high freight costs.
- Consider regional warehouses and local delivery partners to control shipping costs.
- Improve estimated delivery dates using historical delivery performance.
- Monitor delayed orders and improve customer communication when delays occur.
